# 서울 지하철 혼잡도 예측 · 덜 붐비는 출발 시간 추천

서울교통공사 혼잡도 데이터로 역·방향·요일·시간대별 혼잡도를 예측하고,
희망 출발 시간 주변에서 덜 붐비는 출발 시간을 추천하는 Streamlit 데모입니다.
기상청 API허브의 시간별 관측 자료로 **날씨가 이용량에 미치는 영향**을 추정하는 분석 코드도 포함합니다.

## 현재 상태
| 기능 | 상태 |
| --- | --- |
| 혼잡도 예측 + 출발 시간 추천 (1~2구간 환승) | 동작 |
| 승하차 3개년 데이터 통합 (`pipeline/ridership.py`) | 동작 |
| 기상청 시간별 관측 수집 (`collectors/weather_obs.py`) | 작성됨 · 실제 키로 실행 확인 필요 |
| 날씨 효과 추정 (`analysis/weather_effect.py`) | 가짜 날씨로 검증 완료 · 실제 날씨로 실행 필요 |
| 추정한 날씨 효과를 앱 추천에 반영 | **미구현 (다음 단계)** |
| 버스 통합 예측 | 미구현 (지하철 전용) |

## 폴더 구조
```
├── app.py                  Streamlit 화면: 조회 → 예측 → 출발 시간 추천
├── model.py                혼잡도 CSV 로딩, 학습(LightGBM), 평가, 예측
├── recommend.py            출발 시간 추천 로직
├── make_sample_csv.py      동작 확인용 가상 데이터 생성 (분석에는 사용 금지)
├── collectors/
│   ├── kma_client.py       기상청 API허브 공통 호출 (EUC-KR 디코딩, 텍스트 파싱)
│   └── weather_obs.py      서울(ASOS 108) 시간별 관측 수집
├── pipeline/
│   └── ridership.py        승하차 CSV → 날짜×호선×시간 long 형태, 휴일 판별
├── analysis/
│   └── weather_effect.py   날씨 효과 추정 → models/weather_effect.json
├── data/                   (내용은 git 제외)
│   ├── congestion/         지하철혼잡도정보 CSV
│   ├── ridership/          역별 시간대별 승하차인원 CSV (연도별)
│   ├── raw/                수집한 날씨 원본
│   └── processed/          통합·정제 결과
└── models/                 학습된 모델(model.joblib은 git 제외)
```

## 설치
```bash
pip install -r requirements.txt
```

## 1) 앱만 실행하기
1. 서울 열린데이터광장 또는 공공데이터포털에서 **서울교통공사 지하철혼잡도정보** CSV를 받아 `data/congestion/`에 넣습니다.
   (폴더가 비어 있으면 앱 화면에서 직접 업로드해도 됩니다.)
2. 실행합니다. 처음 한 번은 자동으로 학습하고, 이후엔 `models/model.joblib`을 재사용합니다.
```bash
streamlit run app.py
```
CSV를 교체했다면 `models/model.joblib`을 지우거나 앱의 "모델 다시 학습" 버튼을 누르세요.

기대하는 CSV 열: `구분(요일구분), 호선, 역번호, 역명, 상하구분, 5시30분, 6시00분, … , 00시30분` (30분 단위 혼잡도 %).
인코딩은 UTF-8 / CP949 자동 인식입니다. 열 이름이 다르면 `model.py` 상단의 `ID_COLS`, `TIME_RE`, `alias`를 수정하세요.

## 2) 날씨 효과 분석 실행하기
```bash
cp .env.example .env            # .env 에 기상청 API허브 인증키(KMA_AUTH_KEY) 입력
# 승하차 CSV(2023~2025)를 data/ridership/ 에 넣은 뒤:
python -m pipeline.ridership    # data/processed/ridership_hourly.csv 생성
python -m collectors.weather_obs   # 2023-01-01 ~ 2026-01-01 시간별 관측 수집 (약 36회 호출)
python -m analysis.weather_effect  # models/weather_effect.json 생성
```
- 인증키는 https://apihub.kma.go.kr 에서 발급합니다. **`.env`는 절대 커밋하지 마세요.**
- 수집 컬럼(TA, RN, SD_HR3, SD_TOT, WS, HM)이 실제 응답에 있는지 처음 한 번 확인하세요.
  강수량(RN)의 결측값(-9) 규칙은 응답 상단 설명을 확인해 필요하면 조정하세요.

### 분석 방법
시간별 승차 인원(전 호선 합)을 "같은 달·같은 요일그룹·같은 시간"의 중앙값으로 나눈 비율을 만들고,
같은 시간대의 날씨(비·폭우·눈·한파·폭염)로 회귀해 출근/퇴근/낮/저녁 × 평일/주말별 변화율(%)을 구합니다.
설날·추석 같은 휴일은 공휴일 목록 없이 이용량으로 판별합니다(평일인데 같은 해 같은 요일 중앙값의 85% 미만).

## 추천 방식
후보 출발 시간(10분 간격, ± 탐색 범위)마다 예측 혼잡도를 구하고,
`혼잡도 + 불편 비용 × (희망 시간과의 차이/10분)`이 가장 낮은 시간을 추천합니다.
환승 시 2구간 역에는 이동 시간만큼 뒤의 시각을 적용합니다.

## 한계
- 혼잡도 CSV는 2년 주기 조사 스냅숏이라 날짜가 없어 날씨와 직접 조인할 수 없고, 시계열 검증도 불가능합니다.
  그래서 학습에 없던 역 20%로 평가합니다.
- 날씨 효과는 승차 인원 기준 상관관계이며 인과가 아닙니다. 승차 인원 변화율을 혼잡도에 그대로 적용하는 것은 근사입니다.
- 기대치를 같은 달 중앙값으로 잡기 때문에 "그 달 평소보다 춥다/덥다"는 편차 효과만 반영됩니다.
